# Cloud Engineering Projects ☁️

A collection of hands-on cloud engineering projects built during my learning journey. These projects demonstrate practical AWS skills using Infrastructure as Code (Terraform), serverless architecture, and cloud-native best practices.

## 🎯 Purpose

This repository serves as a portfolio of cloud engineering projects, showcasing:
- Infrastructure as Code (IaC) with Terraform
- AWS services and architecture patterns
- Cost optimization and free-tier usage
- Local development with LocalStack
- CI/CD pipelines and automation

## 💰 Cost Approach

All projects are designed to run within **AWS Free Tier** limits. Each project includes:
- Cost estimation
- Free tier resource usage
- Cleanup scripts to avoid unexpected charges

## 📖 Learning Path

This repository follows a structured learning approach:
1. **Project 1**: Serverless fundamentals (Lambda, API Gateway, DynamoDB)
2. **Project 2**: CI/CD and automation
3. **Project 3**: Containerization (ECS/EKS)
4. **Project 4**: Advanced architecture patterns
